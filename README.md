# 鲁迅日记·百年前的今天

**Lu Xun Diary · A Century Ago Today**

每天读一段鲁迅一百年前写下的日记原文。

> **公开范围说明（请先阅读）：**
> 本仓库是项目的**公开代码版**，**不包含** `data/years/` 中的完整馆方日记转录，因此不能直接展示完整内容。完整数据因版权/转载授权尚未确认，暂不公开。README 中的界面截图来自本地完整数据版本，仅用于展示项目界面。

## 项目简介

《鲁迅日记·百年前的今天》是一个“每天读一段原文”的静态阅读项目：默认按北京时间找到一百年前的今天，展示鲁迅当天日记原文，并支持按年份、月份、日历和日期浏览。

项目只做原文阅读，不提供 AI 概述、白话翻译或历史解读。缺失日、原稿散佚和来源缺日会明确说明，不用相邻日期替代。

## 项目功能

- 默认展示“百年前的今天”
- 年份选择与跨年浏览
- 月份标签、日历、日期输入和前后日导航
- 日期深链，例如 `#d=1926-10-21`
- 缺失日、来源缺日和覆盖范围外日期的明确状态
- 1926 年人物/作品索引（仅当相应数据存在时显示）
- 纯静态、无后端、无数据库、无第三方运行时依赖

## 技术实现

- 纯静态 HTML/CSS/JavaScript
- 无构建工具、无 npm 依赖、无后端
- 按年份懒加载 JSON 数据
- 所有资源使用相对路径，可直接放在任意静态服务器或 Pages 子路径下
- 不调用第三方 API
- 页面外部链接仅为馆方资料页面和维基文库对校页面

主要文件：

```text
index.html
styles.css
app.js
quote.js
screenshots/
data/README.md
```

## 数据结构与本地运行

页面期望的数据结构如下（**本仓库不包含这些文件**）：

```text
data/
└─ years/
   ├─ index.json
   ├─ 1912.json
   ├─ …
   └─ 1936.json
```

单条日条包含 `date`、`original_text`、`heading`、`source` 等字段；年份文件还包含月份、附录和来源元数据。字段说明见 `data/README.md`。

本地预览：

```bash
python -m http.server
```

打开终端输出的本地 URL。**由于本仓库没有年份 JSON，页面会显示数据载入失败提示，这是预期的公开代码版状态。** 只有在你本地放入经授权的数据后，完整阅读功能才可工作。

## 史料来源

完整数据版本的转录来源为：

> 北京鲁迅博物馆（北京新文化运动纪念馆）资料查询在线检索系统  
> `http://www.luxunmuseum.com.cn/cx/`

数据文件中保留了馆方记录 ID、正文 URL 和月份来源信息。**本公开仓库不包含馆方原始 HTML 快照，也不包含完整日记转录。**

## AI 辅助开发说明

本项目在开发过程中使用 **DeepSeek Harness（deepseek-flash）** 辅助代码编写、数据解析、验证脚本和文档整理。

- 日记正文全部来自馆方网页转录，不是 AI 生成或改写。
- 缺失日和来源缺口没有被 AI 推测填补。
- 没有使用 AI 生成页面概述、历史解读或人物知识图谱。
- 页面与数据经过来源快照和真实浏览器回归测试。
